# Water Quality Data Imputation

Flujos de reconstruccion de valores faltantes y tratamiento de outliers en bases de calidad del agua.

## Objetivo

Comparar y aplicar metodos de imputacion para reconstruir datos faltantes en series o tablas de calidad del agua, incluyendo estrategias basadas en media, KNN e imputacion iterativa.

## Contenido

- Scripts de imputacion.
- Scripts de limpieza y outliers.
- Tablas reconstruidas seleccionadas.
- Bases de ejemplo para reproducibilidad.

## Estructura

```text
imputation/
outliers/
```

## Stack

- Python
- pandas
- numpy
- scikit-learn
